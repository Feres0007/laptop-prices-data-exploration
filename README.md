# Laptop Prices — Exploration de données

Notebook d'introduction à l'analyse de données avec **pandas**, basé sur le jeu de données public `laptops.csv` (Alexey Grigorev).

## Contenu

- Chargement du CSV depuis son URL publique.
- Première inspection du DataFrame : `head()`, affichage des lignes, dimensions.

Le notebook a été renommé en `laptop_prices_exploration.ipynb` pour que le nom décrive le projet.

## Ouverture

```bash
pip install pandas jupyter
jupyter notebook laptop_prices_exploration.ipynb
```

## Source des données

`http://raw.githubusercontent.com/alexeygrigorev/datasets/master/laptops.csv`
